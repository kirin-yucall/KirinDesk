# KirinDesk

**P2P 直连优先 · 端到端加密 · 无中心服务器依赖 · 纯公益开源**

KirinDesk 是一款远程桌面 / 远程 Shell / 文件传输软件：设备之间优先点对点直连，数据全程端到端加密，不经过任何第三方中转；直连不可达时，可选的自建服务器仅负责辅助打洞牵线与兜底，数据面仍保持双端直连与加密。

## 这是什么

- **远程桌面**：跨设备屏幕共享与控制，硬件加速编码，多显示器支持，隐私模式（黑屏 / 锁屏）
- **远程 Shell**：无头服务器远程终端，替代 SSH，无需暴露固定端口
- **文件传输**：双向加密传输，断点续传，GUI 拖拽 / 复制粘贴两种方式
- **剪贴板共享**：跨设备复制粘贴（含文件内容直贴）
- **无人值守访问**：白名单 / 已知设备自动放行，免审批弹窗
- **多平台**：Windows（GUI + 命令行）、Linux、macOS；安卓端作为被控端支持

## 安全模型（要点）

- 端到端 AEAD 加密，每次会话独立派生密钥
- 指纹确认（known-hosts 机制）：首次连接核对对端指纹
- 挑战码 + 签名双重认证，敏感凭据加密存储
- 域名 + 设备 ID 白名单访问控制（而非易变的 IP）
- 可选服务器完全自建；服务器不可读任何会话内容

## 下载

请到本仓库 **Releases** 页面下载各版本安装包。

**下载后务必校验 SHA-256**：每个附件旁提供 `.sha256` 侧车文件，用你操作系统的哈希工具核对安装包哈希与之一致后再运行。

## 安全提醒

1. **首次连接先核对指纹**：连接前请通过当面 / 电话等独立渠道核对对端设备指纹，防止中间人。
2. **妥善保管挑战码**：挑战码等同于门禁钥匙，切勿发给无关人员；建议定期更换。
3. **会话权限须知**：已建立的会话对远端磁盘具备读写能力——请只与可信设备连接；如怀疑挑战码泄露，立即更换并断开相关设备。
